# Vanilla Todo App

HTML, CSS, Vanilla JavaScript로 구현한 Todo 웹 앱입니다.

## 주요 기능

- Todo 추가 / 수정 / 완료 / 삭제
- 전체 / 진행 중 / 완료 상태별 필터링
- 날짜별 Todo 관리
- localStorage를 이용한 데이터 저장 및 복원
- 현재 선택된 날짜의 Todo 초기화

## 사용 기술

- HTML
- CSS
- Vanilla JavaScript
- localStorage

## 실행 방법

`index.html` 파일을 브라우저에서 열거나 VSCode Live Server로 실행합니다.

## 주요 파일

- `index.html` : 화면 구조
- `style.css` : 스타일
- `app.js` : Todo 기능 구현
